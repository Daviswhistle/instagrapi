# 팔로잉 새 글 자동 좋아요

`instagrapi`의 홈 피드와 팔로잉 목록을 이용해 **내가 실제로 팔로우하는 계정의 새 게시물**에만 좋아요를 누르는 데스크톱 앱입니다. 비개발자가 실행 파일을 받아 바로 사용할 수 있도록 Tkinter와 PyInstaller로 구성했습니다.

> Instagram이 일반 사용자 계정에 제공하는 공식 자동 좋아요 기능이 아닙니다. 계정 확인, 일시 제한 또는 기능 변경이 발생할 수 있습니다. 기본값보다 공격적으로 설정한다고 안전해지는 것은 아니며, 낮은 한도부터 사용해야 합니다.

## 친구에게 전달할 실행 파일 만들기

1. 저장소의 **Actions** 탭을 엽니다.
2. **Build Following Auto Like** 워크플로를 선택합니다.
3. **Run workflow**를 눌러 실행합니다.
4. 완료된 실행의 **Artifacts**에서 운영체제에 맞는 압축 파일을 내려받습니다.
5. 압축을 풀어 친구에게 전달합니다.

- Windows: `FollowingAutoLike.exe`
- macOS: `FollowingAutoLike.app`

실행 파일은 코드 서명이 되어 있지 않습니다. Windows SmartScreen이 표시되면 파일 출처를 직접 확인한 뒤 실행해야 합니다. macOS에서는 앱을 Control-클릭하거나 우클릭한 다음 **열기**를 선택하면 최초 실행을 승인할 수 있습니다. 운영체제 보안 기능을 전역으로 끄지는 마세요.

## 사용 방법

1. Instagram 사용자 이름을 입력합니다. 앞의 `@`는 있어도 됩니다.
2. 처음 로그인할 때만 비밀번호를 입력합니다. 비밀번호는 디스크에 저장하지 않습니다.
3. 필요하면 하루 한도와 확인 간격을 조정한 뒤 **시작**을 누릅니다.
4. 2단계 인증이 켜져 있으면 앱이 인증 코드를 묻습니다.
5. 첫 실행은 현재 홈 피드의 게시물을 기준선으로 저장하고 좋아요를 누르지 않습니다.
6. 이후 확인부터 새로 발견된 게시물을 처리합니다. 앱이 열려 있는 동안만 동작합니다.

**중지**는 대기 중이든 좋아요 직전이든 현재 작업을 취소합니다. **계정 데이터 지우기**는 저장된 세션과 처리 기록을 삭제하며, 다음 실행을 다시 첫 실행으로 만듭니다.

## 기본 동작

앱은 다음 조건을 모두 만족하는 게시물만 후보로 선택합니다.

- 홈 피드에 나타난 게시물
- 현재 팔로잉 목록에 실제로 포함된 계정의 게시물
- 설정한 최근 시간 안에 올라온 게시물
- 아직 좋아요를 누르지 않은 게시물
- 이전 실행에서 처리하지 않은 게시물
- 광고나 추천 게시물로 표시되지 않은 게시물
- 본인 계정의 게시물이 아닌 게시물

기본 설정은 다음과 같습니다.

- 하루 최대 좋아요: 20회
- 피드 확인 간격: 30분
- 새 게시물 좋아요 비율: 90%
- 새 글로 인정하는 시간: 24시간
- 좋아요 전 대기: 60~150초

좋아요 비율 때문에 건너뛴 게시물은 다음 확인에서 다시 시도하지 않습니다. 요청 제한, 계정 확인 또는 좋아요 오류가 발생하면 반복 요청하지 않고 즉시 중지합니다.

## 로컬에 저장되는 정보

비밀번호는 저장하지 않습니다. 대신 로그인 후 생성되는 세션 설정과 아래 상태만 사용자 계정의 앱 데이터 폴더에 저장합니다.

- 마지막으로 사용한 사용자 이름과 동작 설정
- Instagram 로그인 세션과 쿠키
- 이미 확인한 게시물 ID
- 오늘 누른 좋아요 횟수

세션 파일은 비밀번호가 아니지만 계정 접근에 쓰일 수 있는 민감한 데이터입니다. 다른 사람에게 전달하거나 동기화 폴더에 올리지 마세요. 앱의 **저장 폴더 열기** 버튼으로 위치를 확인할 수 있습니다.

- Windows: `%APPDATA%\FollowingAutoLike`
- macOS: `~/Library/Application Support/FollowingAutoLike`
- Linux: `${XDG_CONFIG_HOME:-~/.config}/FollowingAutoLike`

## 문제가 생겼을 때

- **비밀번호 오류**: 공식 Instagram 앱에서 같은 정보로 로그인되는지 확인합니다.
- **계정 확인 필요**: 자동 재시도하지 말고 공식 앱에서 확인 절차를 끝낸 뒤 다시 실행합니다.
- **잠시 후 다시 시도**: 앱을 중지하고 공식 앱에서 계정 상태를 확인합니다. 한도나 간격을 더 보수적으로 조정합니다.
- **세션이 계속 만료됨**: 계정 데이터를 지운 뒤 공식 앱과 동일한 네트워크에서 다시 로그인해 봅니다.
- **오류 보고**: 화면의 **로그 복사**를 눌러 로그를 전달합니다. 비밀번호나 세션 JSON은 첨부하지 마세요.

## 개발 실행

Python 3.10 이상과 Tkinter가 필요합니다.

```bash
python -m pip install -e .
python apps/following_auto_like/app.py
```

회귀 테스트:

```bash
python -m pytest -q tests/regression/test_following_auto_like.py
```

로컬 패키징 예시:

```bash
python -m pip install "pyinstaller>=6.16,<7"
pyinstaller --noconfirm --clean --onefile --windowed \
  --name FollowingAutoLike --paths . \
  apps/following_auto_like/app.py
```

## 설계 원칙

- 기존 `instagrapi` 라이브러리 코드는 변경하지 않고 앱을 `apps/` 아래에 격리합니다.
- 홈 피드만 신뢰하지 않고 `user_following` 결과와 교차 확인합니다.
- 최초 기준선으로 과거 게시물 일괄 좋아요를 방지합니다.
- 상태 파일은 원자적으로 저장하고 게시물 ID 목록은 최근 5,000개로 제한합니다.
- 계정 제한 신호를 우회하거나 자동으로 해결하지 않습니다.
